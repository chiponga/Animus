# ROI Ledger

ROI Ledger registra ganhos operacionais de orquestracao.

## Metricas

| Metrica | Como medir |
|---|---|
| Tempo economizado | tempo manual estimado - tempo com Animus |
| Cliques removidos | passos antes - passos depois |
| Retrabalho evitado | falhas/gargalos removidos |
| Risco reduzido | gates adicionados, rollback, validacao |
| Velocidade de entrega | lead time antes vs depois |
| Qualidade | bugs, regressao, aprovacao em gates |

## Template

```text
ROI Entry:
Processo:
Antes:
Depois:
Tempo economizado:
Risco reduzido:
Evidencia:
Proxima automacao:
```

## Regras

- Nao inventar numeros.
- Se nao houver dado, marcar como estimativa.
- Separar economia real de hipotese.
- Usar Oracle quando houver analise de metrica.
