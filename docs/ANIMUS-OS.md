# Animus OS

Animus OS e a metodologia operacional do Animus para transformar pedidos soltos em trabalho coordenado por agentes.

## Ideia central

IA solta gera caos quando tenta fazer tudo ao mesmo tempo. Animus reduz caos criando:

- orquestracao central.
- agentes especialistas.
- objetos vivos de trabalho.
- camadas de contexto.
- quality gates.
- registro de ROI.

## Fluxo

```text
Pedido -> Discovery -> Work Object -> Context Layers -> Agentes -> Quality Gates -> Entrega
```

## Papeis

- Animus: recebe, decide, delega, valida e entrega.
- Especialistas: executam fatias claras.
- Sentinel: valida qualidade e regressao.
- Oracle: mede estrategia, dados e ROI.
- Chefe: aprova direcao e decisoes sensiveis.

## Regra de ouro

Se nao esta estruturado como objeto de trabalho, ainda e conversa. Se nao passou por gate, ainda nao esta pronto.
