# Context Layers

Animus usa tres camadas para distribuir contexto sem sobrecarregar os agentes.

## Estrategica

O que importa: ICP, oferta, objetivo, identidade, metrica.

## Tatica

Como fazer: plano, dependencias, tarefas, criterios.

## Operacional

O que executar: arquivo, comando, tela, copy, teste, entrega.

## Regra

Cada agente recebe apenas o contexto necessario para sua responsabilidade.
