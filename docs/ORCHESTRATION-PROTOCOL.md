# Orchestration Protocol

## Estados

1. Intake.
2. Discovery.
3. Work Object.
4. Routing.
5. Execution.
6. Quality Gate.
7. Delivery.
8. Learning.

## Checklist rapido

- O objetivo esta claro?
- Existe dono?
- Existe criterio de aceite?
- Quais agentes precisam atuar?
- Qual contexto cada agente precisa?
- Qual gate aprova ou barra?
- Qual evidencia sera entregue?
