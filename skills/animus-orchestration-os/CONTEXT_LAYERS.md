# Context Layers

Use camadas para evitar que agentes recebam contexto demais ou contexto errado.

## Camada 1: Estrategica

Define "o que importa".

Inclui:
- identidade.
- ICP.
- oferta.
- posicionamento.
- objetivo de negocio.
- restricoes permanentes.
- metricas de sucesso.

Quem mais usa:
- Animus.
- Oracle.
- Victor.
- Apollo.

## Camada 2: Tatica

Define "como vamos fazer".

Inclui:
- plano.
- arquitetura.
- briefing.
- tarefas.
- criterios de aceite.
- dependencias.
- riscos.

Quem mais usa:
- Animus.
- Felipe.
- Atlas.
- Helena.
- Titan.
- Sentinel.

## Camada 3: Operacional

Define "o que executar agora".

Inclui:
- arquivo.
- comando.
- componente.
- rota.
- tela.
- copy.
- teste.
- checklist.

Quem mais usa:
- Atlas.
- Helena.
- Victor.
- Aegis.
- Titan.
- Sentinel.

## Regra de heranca

Cada agente recebe:

```text
1. Objetivo estrategico minimo.
2. Plano tatico relevante.
3. Operacao exata que deve executar.
```

Nunca envie o briefing inteiro se o agente precisa apenas de uma fatia.
