# Work Objects

Work Objects sao unidades rastreaveis de trabalho.

## Tipos

- Project.
- Task.
- Briefing.
- Decision.
- Deliverable.
- Quality Gate.
- Incident.
- Experiment.

## Template

```text
Work Object:
Tipo:
Objetivo:
Escopo:
Fora de escopo:
Dono:
Agentes:
Insumos:
Restricoes:
Criterios de aceite:
Gates:
Status:
Riscos:
Proximo passo:
```

## Status

`draft`, `ready`, `running`, `waiting_user`, `blocked`, `review`, `approved`, `delivered`, `archived`.
