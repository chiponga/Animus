========================================
COMO INSTALAR O ANIMUS
Gradsky + PM2 + Claude Code + Telegram
========================================

Repositorio oficial:
https://github.com/chiponga/Animus.git

A arquitetura oficial atual e:

Telegram <-> bot Python via PM2 <-> claude -p <-> subagentes Claude Code


========================================
PRE-REQUISITOS
========================================

- Container Gradsky persistente com /workspace.
- Conta Claude Pro ou Max com Claude Code autenticado.
- Bot Telegram criado no @BotFather.
- Seu user_id Telegram obtido no @userinfobot.
- Opcional: OPENAI_API_KEY para audio de entrada.
- Opcional: ELEVENLABS_API_KEY para audio de saida.
- Opcional: DATABASE_URL Supabase/Postgres para memoria persistente.
- Opcional: MUAPI, GEMINI, VALIDEMAIL, TAVILY para skills premium.


========================================
PASSO 1 - CRIAR BOT TELEGRAM
========================================

1. Abra o Telegram.
2. Procure @BotFather.
3. Envie /newbot.
4. Escolha nome e username do bot.
5. Copie o token.

Para pegar seu user_id:
1. Procure @userinfobot.
2. Envie /start.
3. Copie o numero retornado.


========================================
PASSO 2 - INSTALAR NO GRADSKY
========================================

Dentro do container Gradsky:

```bash
cd /workspace
git clone https://github.com/chiponga/Animus.git
cd Animus
bash install.sh
```

O instalador executa:

- `bootstrap.sh` para instalar dependencias.
- Criacao/atualizacao do `.env`.
- Symlink `.claude/skills -> ../skills`.
- Inicio do bot com PM2.
- Validacao basica do ambiente.


========================================
PASSO 3 - LOGIN CLAUDE CODE
========================================

Se o Claude Code ainda nao estiver autenticado:

```bash
claude /login
```

Depois valide:

```bash
claude auth status
```


========================================
PASSO 4 - RESPONDER O WIZARD
========================================

O `install.sh` pergunta:

1. Nome do agente.
2. Como o agente deve chamar voce.
3. Empresa/produto.
4. Token do Telegram.
5. Seu user_id Telegram.
6. Chaves opcionais para audio, memoria, imagem, analytics e validacao de email.

Se nao tiver uma chave opcional, deixe em branco. A skill correspondente fica dormente.


========================================
PASSO 5 - VALIDAR
========================================

```bash
bash scripts/validate.sh
```

Esperado:

- PM2 com `animus-bot` online.
- Claude Code autenticado.
- `.env` com permissao segura.
- `.claude/skills` apontando para `skills/`.
- 9 agentes em `.claude/agents/`.
- Telegram respondendo `getMe`.


========================================
PASSO 6 - TESTAR NO TELEGRAM
========================================

1. Abra o chat do bot.
2. Envie "oi".
3. O bot deve reagir, processar e responder.

Exemplos:

- "Animus, revise este projeto para producao usando Felipe."
- "Animus, crie uma API Bun + Elysia + Drizzle + MySQL."
- "Animus, faca uma auditoria de seguranca nesse backend."
- "Animus, crie uma copy de landing page com Victor."
- "Animus, valide esse deploy com Titan e Sentinel."


========================================
ARQUITETURA RESUMIDA
========================================

Telegram
  -> animus-bot/bot.py
  -> PM2 mantem o processo vivo
  -> cada mensagem chama claude -p
  -> Animus roteia para subagentes
  -> resposta consolidada volta ao Telegram

Subagentes principais:

- Atlas: engenharia, codigo, arquitetura.
- Aegis: seguranca.
- Helena: UI/UX.
- Victor: copy e marketing.
- Sentinel: QA e confiabilidade.
- Titan: DevOps, infra e deploy.
- Apollo: SDR, vendas e growth.
- Oracle: analytics e estrategia.
- Felipe: senior dev OS, Gradsky, produto e producao.


========================================
COMANDOS DO DIA A DIA
========================================

```bash
pm2 status
pm2 logs animus-bot
pm2 restart animus-bot
tail -f animus-bot/logs/bot.log
bash scripts/validate.sh
bash scripts/backup.sh
bash scripts/upgrade.sh
bash scripts/rollback.sh
```


========================================
PROBLEMAS COMUNS
========================================

Bot nao responde:
```bash
pm2 logs animus-bot --lines 50
```

Claude nao autenticado:
```bash
claude /login
```

Skills nao aparecem:
```bash
ls -la .claude/skills
```

Telegram bloqueado:
- confira `TELEGRAM_BOT_TOKEN`.
- confira `ALLOWED_USERS`.
- envie `/start` no bot.
